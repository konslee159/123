# 원본 소프트웨어 개발 계획서 요약 (틀)

> 팀 "SignBridge" (프로젝트명 손잇다) 개발계획서(2026.07.20)에서 이번 프로토타입이 참고한 부분만
> 요약해 둡니다. 전체 원문은 업로드한 PDF를 참고하세요.

- **개발 목표**: 영상통화 중 AI가 수어 ↔ 음성을 양방향 실시간 번역해, 통역사 없이 청각장애인과
  비수어 사용자가 대화할 수 있게 한다.
- **주요 기능**: 실시간 수어 인식, 수어→텍스트/음성 변환, 양방향 실시간 번역, 통화 요약.
- **시스템 구조**: 웹 클라이언트(WebRTC) — 실시간 통신 서버 — AI 추론 서버(수어 인식: MediaPipe
  + CNN/Transformer, 음성 인식/합성: Whisper 등) — 백엔드(세션/로그/요약) — 통합 DB.
- **학습 데이터셋**: AIHub "수어 영상" (dataSetSn=103), 수어문장 2,000종·단어 3,000종, Pose/손/얼굴
  키포인트 JSON 포함.

## 이번 세션에서의 우선순위 (사용자 지시, 원문 틀보다 우선)

1. 수어 인식 → 문자 번역 → TTS 출력
2. 일반인 음성 → **아바타 대신 실제 촬영 수어 영상**을 반대로 내보내기
3. 데이터는 자체 촬영이 기본, AIHub는 일상 대화에 필요한 부분만 선별 사용
4. 수어→TTS 사이에 ChatGPT API로 문장을 한 번 다듬기
5. 위 1~4번이 이 PDF 틀보다 우선순위가 높음

이 프로토타입 저장소의 모든 설계 결정은 위 1~5번을 기준으로 내렸습니다. 통화 요약, 로그인/세션,
통합 DB 등 계획서의 나머지 항목은 이번 우선순위에는 없으므로 이번 단계에서는 구현하지 않았고,
`docs/ARCHITECTURE.md`에 "다음 단계"로만 남겨 두었습니다.
